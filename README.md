# Hyvä Compatibility Module for BitPay Checkout

Hyvä Compatibility module for Bitpay_BPCheckout
 
## Installation

### Via packagist.com

The module can be installed using composer via packagist.com:

1. Install via composer
    ```
    composer require bitpay/module-bpcheckout-hyva-compatibility
    ```
2. Enable module
    ```
    bin/magento setup:upgrade
    ```
